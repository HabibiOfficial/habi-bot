# Audio Adzan — HABI AI

Folder ini menyimpan file audio adzan untuk bot.

## Format
- `adzan-nasional.mp3` — adzan nasional (fallback utama)
- `adzan-{kota}.mp3` — adzan khusus kota, contoh: `adzan-jakarta.mp3`

## Prioritas
Bot memakai file lokal terlebih dahulu. Jika tidak ada, bot memakai
fallback daring dan menampilkan credit penyedia aslinya.

## Hak penggunaan
Hanya masukkan file audio yang Anda miliki haknya atau berlisensi bebas
(public domain / creative commons). Jangan masukkan rekaman dari sumber
yang hak ciptanya dilindungi.
